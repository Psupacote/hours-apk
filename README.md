# HOURS — Android Downloads

Official public APK downloads for **HOURS**, the shift, attendance, and earnings tracker.

## Download the latest version

[**Get HOURS for Android**](https://github.com/Psupacote/hours-apk/releases/latest)

Once published, the latest release will include a versioned APK such as `HOURS-0.7.64-b75.apk`.

## Updates

Install a newer APK over your existing HOURS installation. Android may request permission to install apps from your browser. Updating without losing app data requires the same package identity and signing certificate.

This repository contains public downloads only. The source code and signing credentials remain in the separate private development repository.
